# 简历与面试表述

## 推荐项目介绍

**制度查询助手｜AI产品设计与评测实践**：基于AnythingLLM构建面向制造业制度查询的可信RAG Agent，围绕证据相关性、回答边界与异常隔离完成产品定义、评测和迭代验收；代码由AI Coding Agent辅助开发。

## 可使用的量化结果

- 设计14份模拟制度、80条固定回归题及28题独立Dev Set，覆盖版本、部门、无答案、多轮等8类场景，建立6项指标及Bad Case闭环。
- 在同模型和基础RAG参数的单次对照中，引用准确率由290/491（59.06%）提升至127/128（99.22%，另1条待复核）；正确拒答由6/11（另4待复核）到11/11。
- 复盘治理JSON异常引起的中断，推动Schema、有界解析与异常隔离；17/17离线故障注入通过，80题序列结束且无服务级中断，78题有效、2题治理失败。

简历篇幅不足时优先写第一条和引用指标，面试主动补充：模拟制度、单次固定回归、单评审初标，核心准确率有退化。不要省略99.22%的待复核说明。

## 更适合面试展开、慎用作标题的结果

无依据推断：B确认11/80（另6待复核），V1.1有效返回中确认0/78（另1待复核）。分母不同、仍有争议与运行失败，不能写成“消除幻觉100%”。噪声case同样是63/80→确认0/78、另1待复核。

不写“全部80题成功”“准确率整体提升”“全部指标提升”“生产级可靠”“完全自主手写”“未见盲测”“独立双人评审”。可如实写：完成80题全序列，78题有效返回。
